# Requirements: si-units-constants
Status: v1, frozen. Phase 1 of `docs/evolution-plan.md`. Amends `decision-engine` (decision D-25) and `limit-dsl`, additions only.

- **R-01** `limina-core` accepts every SI unit: the 13-symbol table first (unchanged), else a parsed expression built from SI prefixes (SI Brochure, 9th edition 2019, table 7), the SI base units and the derived units with special names (tables 2 and 4), the non-SI units accepted for use with the SI (table 8: min, h, d, au, L, t, ha, eV), the exact conventional units bar (10^5 Pa) and atm (101 325 Pa), Wh, bit and %, with integer exponents (`^n`, `^(-n)`, superscripts) and the operators `*`, `·`, `.`, space and `/`. Anything else is `UnknownUnit`. Celsius and Fahrenheit are never accepted; a pure temperature still needs the temperature types.
- **R-02** `units_for_dimension`, the 13-symbol table and their tests, the API metadata and every verdict stay as they were. One API test changes its error code: a temperature written in `C` is now refused as `IncompatibleDimension` (coulomb) instead of `UnknownUnit`; `°C` and `degC` are still `UnknownUnit`. It is never read as Celsius.
- **R-03** One versioned table of physical constants (`CODATA_VERSION = "CODATA 2022"`), each with symbol, CODATA name, SI value, standard uncertainty, unit, SI exponents and source. Exact derived constants (ħ, σ, R, F) are computed from the defining constants. The NIST file used is kept in `data/constants/codata-2022-allascii.txt`.
- **R-04** The DSL accepts those constants by symbol. A measured constant is evaluated as the interval value ± standard uncertainty, which can only widen a bound, so it can never create a false IMPOSSIBLE. Parameter units may be any SI unit of the parameter's dimension; temperatures stay K only.
- **AC** Unit parser tests: derived units, equivalent compound forms, prefixes and exact factors, refusals. Constant tests: unique symbols; every unit parses to its exponents; derived exact values match every printed NIST digit; μ0 ε0 c² = 1 and α = e²/(4π ε0 ħ c) within the uncertainties. DSL reference tests: Stefan-Boltzmann flux, Newtonian force carrying u(G), electron rest energy in MeV against CODATA, Heisenberg, Coulomb against the atomic unit of force, compound parameter units, dimension refusals.
