# Requirements: public-hosting

## Goal
Run Limina as one container behind Cloudflare for a public demo, with a bounded memory, a per-address limit on the routes that call a language model, and a reliable Forge (`POST /v1/limits/author`). No change to `limina-core`.

## Requirements
- **H-01** The server listens on `LIMINA_API_ADDR` when set, else on `0.0.0.0:$PORT` when `PORT` is set, else on `127.0.0.1:3000` (a local run is never open to the network by default). An invalid value is a startup error that names the variable.
- **H-02** `STATIC_DIR`, when it holds an `index.html`, is served next to the API. A path that is a file is served with its type, `nosniff`, and `no-cache` for `index.html`, one hour otherwise. A path that is not a file and has no extension gets `index.html` (client-side routes). A missing file with an extension is a 404. A path under `/v1/` that matches no route is a JSON 404 `NotFound`, never the page. Only GET and HEAD are served; a path with `..`, a backslash, a colon or a NUL, or whose real path leaves the folder, is a 404.
- **H-03** `/v1/analyze`, `/v1/limits/author` and `/v1/transcribe` share one budget per client address: `LLM_RATE_LIMIT_PER_HOUR` requests per sliding hour (default 15; `0` turns it off; a value that is not a number gives 15). Past it: `429`, code `RateLimited`, a plain message with the wait in minutes, and a `Retry-After` header in seconds. `/healthz`, `/v1/limits`, `/v1/evaluate`, `/v1/capabilities`, `/v1/pipeline`, `/v1/curve`, `/v1/surface` and `/v1/solve` are never limited.
- **H-04** The client address is the connection's, unless `TRUST_PROXY` is `true` (or `1`): then `CF-Connecting-IP`, else the first `X-Forwarded-For` entry, and only when it is a valid address. An IPv6 client is counted by its /64. At most 10 000 addresses are followed; past that the least recently seen is forgotten.
- **H-05** A library user of `AppState` (tests, other binaries) has no limiter unless it asks for one; `AppState::from_env` (the server) turns it on.
- **H-06** At most 50 authored limits are kept in memory. A new one past that drops the oldest, with its agreement status; registering an id again replaces it and makes it the newest.
- **H-07** The Forge's answer of a model is normalized for habitual slips, each one reported in `overrides`: a `kind` that is not `absolute_temperature` or `temperature_difference` is dropped (a plain parameter then takes its first unit as its dimension); exponents written as text are read as an array; exponents among the `units` are removed (and used as the dimension when there is none); a plain parameter whose `units` are known and share one dimension takes that dimension when its own differs. The check of the formula against the bounded dimension, the unit table and the grid checks are never relaxed.
- **H-08** The authoring prompt shows one complete example, asks for unit symbols rather than exponent lists, and forbids declaring a constant as a parameter. A refusal sent back to the model carries a fixed hint for the errors models repeat (reserved name, dimension mismatch, unit not in the table), after the exact error.
- **H-09** One `Dockerfile` at the root: an Angular build, a Rust release build (`--locked`) and a runtime image with the binary and the built app, running as a non-root user, with `PORT=3000`, `STATIC_DIR=/app/static`, `LLM_RATE_LIMIT_PER_HOUR=15`, `TRUST_PROXY=false` and a health check on `/healthz`.
